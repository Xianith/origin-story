## What is it?

You wake up in the **Eternal Library**, a cathedral of living books where every volume holds a realm. Pick a **Warrior**, **Mage** or **Ranger**, cast yourself into a procedurally generated realm, and fight, harvest and loot your way to its boss before the realm crumbles away beneath you.

- ⚔️ **Fast action combat**: telegraphed enemy attacks, elite affixes, boss fights, and a talent tree for each class
- 🌍 **Procedural realms**: new terrain, dungeons, groves and ruins every run, with tiers that scale up as you go
- 🏠 **Your own haven**: build it, store your loot, and craft gear through forging and brewing minigames
- 🐎 **Tame and ride horses**, chop trees, mine rocks, and work your way up the gear tiers
- 👥 **Play together**: real-time multiplayer, parties, and solo or group queues into the Untethered realms
- 📱 **Plays on desktop and phones**

## What powers it

| | |
|---|---|
| 🎮 **[three.js](https://threejs.org/)** | 3D rendering, animation and physics in the browser |
| 💬 **[Discord](https://discord.com/)** | One-click login, plus your community and party hub |
| 🔌 **Node.js + WebSockets** | Real-time multiplayer and server-side enemy AI |
| 🐘 **PHP 8 + MySQL** | Accounts, inventory, quests and the game database |
| 🎨 **[Blender](https://www.blender.org/)** | Characters, armor, creatures and world props, all built with scripts |
| 🌐 **nginx** | Serves the whole thing |
| 🤖 **[Claude Code](https://claude.com/claude-code)** | Built by one dev and an AI pair-programmer |
